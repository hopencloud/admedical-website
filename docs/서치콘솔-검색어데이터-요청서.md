# 서치콘솔 검색어 데이터 뽑기 — 작업 의뢰서

**작성일**: 2026-08-27
**속성**: `admedical.co.kr` (도메인 속성)
**소요**: 10분. 클릭만 하면 되고 색인 요청 같은 할당량 제한 없음.

---

## 배경 — 앞선 보고서에서 밝혀진 것

3개월 노출 7,930회의 분포:

| URL | 클릭 | 노출 | 비중 |
|---|---|---|---|
| /guide/application | 19 | **5,488** | **69%** |
| /guide/target-media | 2 | **1,812** | 23% |
| 기사 31편 전부 | 7 | 약 90 | 1% |

**노출의 92%가 이 두 페이지에서 나온다.** 그런데 CTR 이 각각 0.35%, 0.11% 다.

여기서 갈린다:

- **순위가 낮아서** 노출만 잡히는 것이라면 (20~40위. 2~4페이지도 노출로 계산됨)
  → 제목을 아무리 고쳐도 소용없다. 본문을 그 검색어에 맞게 보강해야 한다.
- **순위는 괜찮은데 안 눌리는 것이라면** (5~10위)
  → 제목·설명 문제다. 그것만 고치면 된다.

**처방이 정반대라, 데이터 없이 손대면 또 헛일이 된다.**
(실제로 직전에 노출 1%짜리 기사 31편 제목을 고치는 헛수고를 했다.)

## 뽑아올 데이터

### A. `/guide/application` 검색어

1. 서치콘솔 → **실적** → 기간 **3개월**
2. **+ 필터 추가** → **페이지** → `정확한 URL` →
   `https://www.admedical.co.kr/guide/application`
3. 하단 표에서 **검색어** 탭 선택
4. 지표 체크박스에서 **클릭수 / 노출수 / CTR / 평균 게재순위 4개 모두 켜기**
   (기본은 클릭·노출만 켜져 있음. **평균 게재순위가 이 작업의 핵심이다**)
5. 노출수 내림차순 정렬 → **상위 20개**를 아래 형식으로 옮겨적기

```
| 검색어 | 클릭 | 노출 | CTR | 평균순위 |
|---|---|---|---|---|
| 의료광고 심의 신청 | 3 | 1,200 | 0.25% | 18.4 |
```

### B. `/guide/target-media` 검색어

위와 동일. 페이지 URL 만 `https://www.admedical.co.kr/guide/target-media` 로.

### C. 사이트 전체 상위 검색어 (참고)

페이지 필터 없이, 3개월 기준 노출 상위 20개. 같은 4개 지표.

## 같이 확인해 줄 것

1. **`/guide/application` 의 평균 게재순위가 10위 이내인 검색어가 있는가?**
   있다면 그 검색어들을 따로 표시.

2. **노출은 많은데 클릭이 0인 검색어**가 있는가? 상위 5개.

3. **색인생성 → 페이지** 리포트에서 `발견됨 - 현재 색인이 생성되지 않음` 목록.
