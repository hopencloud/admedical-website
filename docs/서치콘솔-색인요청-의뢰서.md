# 서치콘솔 색인 생성 요청 — 작업 의뢰서

**작성일**: 2026-08-27  
**대상 사이트**: https://www.admedical.co.kr  
**서치콘솔 속성**: `admedical.co.kr`


## 이 작업을 왜 하는가

구글 서치콘솔 3개월 실적이 이렇다.

| 지표 | 값 |
|---|---|
| 총 노출 | 7,930회 |
| 총 클릭 | 36회 |
| **CTR** | **0.5%** |
| 평균 게재순위 | 7.6 (첫 페이지) |

첫 페이지에 뜨는데도 클릭이 없다. 같은 순위면 보통 3~5% 나온다.
원인은 제목에 독자(병의원 마케팅 담당자)가 검색하는 말이 없어서였다.

2026-08-27 에 **이미 색인된 기사 31편의 `<title>`·`og:title`·`twitter:title` 을 전부 교체**했다.
본문과 h1 은 건드리지 않았다. 검색결과에 보이는 것만 바꿨다.

    전: 의료기관 영업정지 판결, 부당청구 규제의 법적 선례
    후: 부당청구 영업정지 판결, 병원 마케팅에 미치는 영향

    전: SNS 의료광고 심의 주의사항, 인플루언서 활용 시 유의점
    후: 의료광고 심의 기준과 인플루언서 활용 시 주의사항

**재수집이 되어야 이 제목이 검색결과에 반영된다.** 그래서 색인 생성 요청이 필요하다.

## 이미 해둔 것 (중복으로 하지 말 것)

- **IndexNow 전송 완료** — 네이버(`searchadvisor.naver.com/indexnow`) HTTP 200,
  빙(`api.indexnow.org`) HTTP 202. 45개 URL 전부. 매일 발행 후 자동 전송되도록 워크플로에도 붙였다.
- **사이트맵 `lastmod` 정정 완료** — 발행일로 고정돼 있어 "안 바뀐 페이지"로 보이던 것을
  실제 파일 수정일로 바꿨다. 34개 URL 이 오늘 날짜다.
- 구글은 **Indexing API 를 일반 페이지에 열어주지 않는다**(채용공고·라이브 방송 전용).
  그래서 서치콘솔 UI 에서 사람이 눌러야 한다. **이게 이 의뢰서의 이유다.**

## 해야 할 일

서치콘솔에서 아래 URL 들에 **색인 생성 요청**을 넣는다.

절차 (URL 1개당):
1. https://search.google.com/search-console 접속 (속성: `admedical.co.kr`)
2. 상단 검색창에 URL 붙여넣기 → Enter (URL 검사)
3. 검사 완료까지 대기 (10~30초)
4. **[색인 생성 요청]** 클릭
5. "색인 생성 요청됨" 확인 후 다음 URL

### 주의사항

- **하루 할당량이 있다.** 대략 10~20개에서 "할당량 초과" 가 뜬다.
  뜨면 그날은 멈추고 다음 날 이어서 한다. 억지로 더 넣지 말 것.
- 각 요청 사이에 **최소 5초 이상** 간격을 둘 것. 연타하면 자동화로 감지될 수 있다.
- 이 계정에는 **애드센스가 물려 있다**(현재 심사 대기 중). 계정 제재는 치명적이다.
  자동화가 막히거나 캡차가 뜨면 **즉시 중단하고 사람에게 넘길 것.**
- 로그인 정보는 사용자가 직접 입력한다. 비밀번호를 다루지 말 것.
